# Веб-версия «Воплощения»

Статический сайт без сборки: `index.html`, ES-модули в `js/`, стили в `css/`, данные в `data/`.

```sh
py -m http.server 8080 -d web      # запуск из корня проекта
node --test web/tests/*.test.js    # тесты
```

Откройте `http://localhost:8080`.

## Структура

- `js/domain/` — правила: подбор и сортировка каталога, дедлайны, расчёт результата теста. Не зависят от DOM.
- `js/games/` — правила и данные мини-игр, прогресс и серии в `localStorage`.
- `js/ui/` — отрисовка экранов; каждый экран возвращает HTML-строку из состояния.
- `js/app.js` — маршруты, состояние и обработчики событий.
- `css/` — токены дизайна, экраны и адаптив (`responsive.css`: телефон, планшет, компьютер с боковым меню).

Для публикации загрузите папку `web/` на любой статический хостинг (GitHub Pages, Netlify, Vercel).
